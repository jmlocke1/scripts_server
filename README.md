# scripts_server
Scripts para montar un servidor web y sus programas.
¡¡¡IMPORTANTE!!! Estos scripts son para montar un servidor de desarrollo local, no de producción, ya que no establecen las reglas de seguridad necesarias para un entorno de producción.

# Variables privadas
Algunas variables utilizadas son de autenticación de la base de datos, contraseñas y nombres de usuarios. Esos datos deben permanecer siempre privados, sin subirse al servidor. Para evitar que las contraseñas verdaderas se suban al repositorio, se utiliza el fichero variables.sh, el cual está incluido dentro de .gitignore.
El fichero variablesDemo.sh contiene todas las variables que tienes que utilizar, pero con valores falsos de prueba. Debes copiar el contenido de variablesDemo.sh en el fichero variables.sh y cambiar los valores por los que correspondan a tu sistema.
